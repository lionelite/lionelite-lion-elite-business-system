# 01 — Client Intake

Collect only what is needed to build the client's current-state map and identify optimization opportunities.

## Personal / household
- State of residence
- Filing status
- Dependents / intended beneficiaries
- Estimated annual personal income
- Estimated net worth range
- Major liquidity events expected in next 3–5 years

## Trusts
- Trust name
- Revocable or irrevocable
- Grantor or non-grantor status if known
- Trustee(s)
- Beneficiaries
- Date created
- EIN if applicable
- Assets currently owned by trust
- Trust document available? yes/no

## Businesses
For each entity:
- Legal name
- State formed
- Ownership percentages
- Current tax election
- Annual revenue
- Approximate profit
- Payroll / owner compensation
- Valuable IP owned
- Real estate owned
- Debt

## Real estate
For each property:
- Address
- Current owner/entity
- Purchase price / basis
- Estimated value
- Loan balance
- Rental or personal use
- Annual income / expenses
- Depreciation status

## Investments / appreciating assets
- Brokerage assets
- Private-company equity
- Digital assets
- Valuable trademarks / domains / IP
- Notes / private lending
- Other assets expected to appreciate

## Goals
Select priorities:
- Reduce current taxes legally
- Protect appreciating assets
- Move future appreciation outside estate where appropriate
- Simplify ownership
- Improve liability separation
- Create family wealth structure
- Prepare for sale / exit
- Improve real-estate tax efficiency
- Create beneficiary distribution strategy
- Prepare for CPA / attorney implementation
